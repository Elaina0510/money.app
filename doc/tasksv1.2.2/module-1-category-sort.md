# 模块 1：设置页 - 分类管理增强

> 需求编号：#1
> 优先级：高
> 影响范围：前端 SettingsPage.vue

---

## 任务列表

### 1.1 前端 - 分类列表增加排序按钮

- [ ] 在分类列表项的 append 区域添加上移/下移按钮
- [ ] 使用 `mdi-chevron-up` 和 `mdi-chevron-down` 图标
- [ ] 首项隐藏上移按钮，末项隐藏下移按钮

### 1.2 前端 - 实现排序逻辑

- [ ] 点击上移时，与上一项交换 `sort_order`
- [ ] 点击下移时，与下一项交换 `sort_order`
- [ ] 调用 `categoriesStore.editCategory` 保存新排序
- [ ] 调用 `fetchCategories()` 刷新列表

### 1.3 边界处理

- [ ] 预设分类支持排序（`is_preset` 不限制排序）
- [ ] 支出/收入分类各自独立排序
- [ ] 排序变更后立即生效

---

## 验收标准

- [ ] 新增分类后出现在列表末尾
- [ ] 点击上移，分类上移一位
- [ ] 点击下移，分类下移一位
- [ ] 首项无上移按钮，末项无下移按钮
- [ ] 排序后刷新页面，排序保持
