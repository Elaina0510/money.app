# v1.2.3 需求文档

## 版本概述

本版本主要修复 v1.2.2 中发现的问题，优化用户体验，提升功能稳定性。

**版本目标**：修复 7 个 Bug，优化快速记账、账单筛选、登录提示等功能

---

## 需求列表

### 1. 快速记账页 - 标签保存时机优化

**问题描述**：  
在快速记账页输入新标签后按回车，标签就立即保存到数据库了，但账单并未保存。用户可以继续填写其他信息，最后点击保存按钮时账单才保存。这导致标签和账单的保存时机不一致。

**期望行为**：  
输入标签 → 按回车确认标签（仅在界面上显示） → 继续填写其他信息 → 点击保存按钮 → 此时账单和标签一起保存到数据库

**验收标准**：
- [ ] 按回车键只确认标签输入，标签在界面上正确显示
- [ ] 按回车键不将标签保存到数据库
- [ ] 只有点击保存按钮后，账单和标签才一起保存到数据库
- [ ] 如果用户未点击保存就离开页面，新标签不应被保存

**优先级**：高

---

### 2. 快速记账页 - 标签显示异常修复

**问题描述**：  
输入标签后点击页面空白处，标签会变成数字（如"15"、"16"），疑似显示了标签的 ID 而非名称。

**期望行为**：  
点击空白处后，标签应显示标签的名字，而不是 ID。

**验收标准**：
- [ ] 输入标签后点击空白处，标签显示正确的名称
- [ ] 标签显示与账单页回看时一致
- [ ] 无论是否保存，标签显示都应正确

**优先级**：高

---

### 3. 账单页 - 类型筛选功能修复

**问题描述**：  
账单页筛选功能中，选择"收入"、"支出"或"全部"都显示相同的内容，筛选不生效。

**期望行为**：  
- 选择"收入"：只显示收入记录
- 选择"支出"：只显示支出记录
- 选择"全部"：显示所有记录

**验收标准**：
- [ ] 选择"收入"时，列表只显示收入类型的账单
- [ ] 选择"支出"时，列表只显示支出类型的账单
- [ ] 选择"全部"时，列表显示所有账单
- [ ] 筛选结果实时更新，无需手动刷新

**优先级**：高

---

### 4. 账单页 - 筛选状态保持优化

**问题描述**：  
筛选后进入别的页面（如"统计"），再切回账单页，筛选条件会保持，但筛选框显示不正确（显示"全部"和"全部分类"）。

**期望行为**：  
筛选状态应该保持，且筛选框正确显示当前筛选条件。

**验收标准**：
- [ ] 切换页面后，筛选条件保持不变
- [ ] 筛选框正确显示当前选择的"类型"（收入/支出/全部）
- [ ] 筛选框正确显示当前选择的"分类"
- [ ] 筛选结果与筛选框显示一致

**优先级**：高

---

### 5. 登录页 - 错误提示优化

**问题描述**：  
输入错误密码后，提示信息是"重试"而非"密码错误"，提示不准确。

**期望行为**：  
提示"用户名或密码错误"（出于安全考虑，不明确告知是哪个错误）。

**验收标准**：
- [ ] 输入错误密码后，显示"用户名或密码错误"
- [ ] 提示信息清晰、友好
- [ ] 不泄露具体是用户名错误还是密码错误

**优先级**：高

---

### 6. 账单页 - 分类标签联动优化

**问题描述**：  
确认"类型"（收入/支出）后，分类展开页仍然显示全部分类标签，没有根据类型筛选。

**期望行为**：  
- 选择"收入"后，只显示收入分类（如工资、兼职、红包等）
- 选择"支出"后，只显示支出分类（如餐饮、交通等）
- 切换类型时，清空已选分类，显示当前类型的全部分类

**验收标准**：
- [ ] 选择"收入"时，分类展开页只显示收入相关分类
- [ ] 选择"支出"时，分类展开页只显示支出相关分类
- [ ] 切换类型时，自动清空已选分类
- [ ] 切换类型后，分类展开页显示当前类型的全部分类
- [ ] 分类列表与类型对应关系正确

**优先级**：高

---

### 7. 设置页 - 恢复默认分类功能

**问题描述**：  
设置页分类管理栏缺少恢复默认设置的功能，用户无法快速恢复到初始状态。

**期望行为**：  
添加恢复默认设置的按钮，点击后需要二次确认，确认后恢复为默认的分类设置。

**验收标准**：
- [ ] 在分类管理栏添加"恢复默认设置"按钮
- [ ] 点击按钮后弹出二次确认对话框
- [ ] 确认后恢复为默认的分类设置（包括分类列表和排序）
- [ ] 恢复后用户自定义的分类会被删除
- [ ] 恢复操作不可撤销，需明确提示用户

**优先级**：高
