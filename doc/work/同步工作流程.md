## 一、首次服务器部署

### 1. 初始化服务器

```bash
# SSH 或 Workbench 登录服务器后执行
cd /www/wwwroot

# 上传项目代码（通过宝塔面板文件管理器上传 tar 包）
# 或者配置 SSH 密钥后 git clone
git clone <你的仓库地址> money-app
```

### 2. 安装系统依赖

```bash
cd /www/wwwroot/money-app
chmod +x setup.sh
sudo bash setup.sh      # 安装 Git、Python、Supervisor 等系统依赖
```

> **注意**：setup.sh 只安装系统依赖，不创建虚拟环境。虚拟环境由 deploy.sh 自动创建。

### 3. 配置环境变量（可选）

**deploy.sh 会自动生成 .env 文件**，但**仅写入 SECRET_KEY**。其余变量（`DATABASE_URL`、`UPLOAD_DIR` 等）由 [config.py](backend/app/config.py) 中的默认值自动处理，无需手动配置。

如需手动配置，可以编辑 `.env` 文件：

```bash
vim /www/wwwroot/money-app/.env
```

**环境变量说明**（参考 `.env.example`）：
```env
# 认证密钥（deploy.sh 会自动生成，无需手动配置）
SECRET_KEY=your_random_secret_key_here

# 数据库路径
# Python 模式默认：backend/money.db
# Docker 模式默认：/data/db/money.db
DATABASE_URL=sqlite+aiosqlite:///data/db/money.db

# Token 过期时间（分钟），默认 7 天
ACCESS_TOKEN_EXPIRE_MINUTES=10080

# 文件上传目录
UPLOAD_DIR=/data/uploads
MAX_FILE_SIZE=10485760
MAX_TOTAL_UPLOAD_SIZE=524288000
```

### 4. 执行部署脚本

**deploy.sh 会自动完成以下操作**：
- 创建 Python 虚拟环境（`backend/venv`）
- 安装依赖（使用阿里云镜像）
- 生成 `.env` 配置文件（包含 SECRET_KEY）
- 配置 supervisor
- 启动应用

```bash
cd /www/wwwroot/money-app
chmod +x deploy.sh
sudo bash deploy.sh      # 部署应用（Python 模式，默认 80 端口）

# 或者使用 Docker 模式（需要能访问 Docker Hub）
sudo bash deploy.sh docker  # Docker 模式（8000 端口，通过 docker-compose 映射到 80）
```

### 5. 验证

```bash
# 检查应用状态
supervisorctl status money-app

# 检查端口是否监听（Python 模式监听 80 端口）
netstat -tlnp | grep :80

# 查看日志
tail -f /var/log/money-app.out.log
```

浏览器访问 `http://<你的服务器公网IP>` 确认应用正常。

> **端口说明**：
> - Python 直接部署模式：应用监听 **80 端口**（可直接通过 IP 访问）
> - Docker 模式：应用监听 **8000 端口**，通过 docker-compose 映射到主机 **80 端口**

**验证要点**：
- 访问首页是否正常显示
- 测试登录/注册功能
- 测试记账功能
- 查看统计数据是否正确

## 二、日常开发部署流程

### 流程图

```
本地修改代码 → 本地测试 → git add + commit → git push → 服务器 git pull → supervisorctl restart
```

### 详细步骤

#### 1. 本地修改代码

在本地电脑（Windows）修改代码。

> **改动范围判断**：
> - **只改了后端**（`backend/` 下的 .py 文件）→ 跳过步骤 3，直接提交
> - **只改了前端**（`frontend/` 下的 .vue/.js/.ts 文件）→ 必须执行步骤 3（`npm run build`）
> - **两者都改了** → 两个都要做

#### 2. 本地测试

```powershell
# 启动后端
cd h:\code\money.app\backend
python -m uvicorn app.main:app --reload --port 8000

# 启动前端（另一个终端）
cd h:\code\money.app\frontend
npm run dev
```

**本地访问地址**：
- 前端：http://localhost:5173
- 后端 API：http://localhost:8000/docs

确认修改没问题后继续下一步。

#### 3. 构建前端（如果修改了前端代码）

```powershell
cd h:\code\money.app\frontend
npm run build
```

#### 4. 提交并推送到 GitHub

```powershell
cd h:\code\money.app
git status          # 检查是否有 .env、money.db 等敏感文件被意外加入
git add .
git commit -m "fix: 修复xxx问题"
git push origin main
```

> **⚠️ 提交前务必检查** `git status` 输出中没有以下文件：
> - `.env`（包含 SECRET_KEY）
> - `money.db`（包含所有财务数据）
> - `backend/uploads/`（包含上传的图片）
> - `*.tar.gz`（可能包含上述文件的打包）
>
> `.gitignore` 已配置排除这些文件，但仍需确认。

#### 5. 服务器更新部署

登录宝塔面板 → **终端** 或 Workbench 远程连接，执行：

**Python 模式**：
```bash
cd /www/wwwroot/money-app

# 拉取最新代码（包含后端和前端 dist）
git pull origin main

# 重启应用
supervisorctl restart money-app
```

> **判断是否需要重启**：
> - 只改了前端（`frontend/dist/` 有更新）→ 拉取后**不需要**重启，静态文件直接生效
> - 改了后端代码 → 拉取后**必须**重启（`supervisorctl restart money-app`）
> - 改了 `requirements.txt`（新增依赖）→ 拉取后需要进入虚拟环境重新安装：
>   ```bash
>   source backend/venv/bin/activate
>   pip install -i https://mirrors.aliyun.com/pypi/simple/ -r backend/requirements.txt
>   supervisorctl restart money-app
>   ```

**Docker 模式**：
```bash
cd /www/wwwroot/money-app

# 拉取最新代码
git pull origin main

# 重新构建并重启（如果依赖有变化）
docker compose down
docker compose build
docker compose up -d

# 或者只是重启（如果只有代码变化）
docker compose restart
```

#### 6. 验证

浏览器访问 `http://<你的服务器公网IP>` 确认修改生效。

## 三、数据同步方案

### 推荐方案：不同步

本地开发环境和服务器生产环境的数据（数据库、上传文件）建议**分开管理，不同步**：

- **本地**：开发测试用，可随意造测试数据
- **服务器**：真实数据，用户使用

每次修改代码后，只需要 `git push` → `git pull` → `supervisorctl restart` 即可，无需同步数据。

### 需要同步数据时

**从服务器下载数据库到本地（调试用）：**

- Python 模式：通过宝塔面板：文件 → `/www/wwwroot/money-app/backend/` → 下载 `money.db`
- Docker 模式：通过宝塔面板：文件 → `/www/wwwroot/money-app/data/db/` → 下载 `money.db`

**从本地上传数据库到服务器：**

- Python 模式：通过宝塔面板上传 `money.db` 到 `/www/wwwroot/money-app/backend/`
- Docker 模式：通过宝塔面板上传 `money.db` 到 `/www/wwwroot/money-app/data/db/`

> **注意**：上传数据库前请先停止应用，避免数据库锁导致迁移失败。

### 数据备份

#### 手动备份

**Python 模式**：
```bash
# 备份数据库
cp /www/wwwroot/money-app/backend/money.db /www/wwwroot/money-app/backend/money.db.bak

# 备份上传文件
tar -czf /www/wwwroot/money-app-backup-$(date +%Y%m%d).tar.gz /www/wwwroot/money-app/backend/uploads/
```

**Docker 模式**：
```bash
# 备份数据库
cp /www/wwwroot/money-app/data/db/money.db /www/wwwroot/money-app/data/db/money.db.bak

# 备份上传文件
tar -czf /www/wwwroot/money-app-backup-$(date +%Y%m%d).tar.gz /www/wwwroot/money-app/data/uploads/
```

#### 自动备份（推荐配置）

使用 crontab 实现每日自动备份，防止数据丢失：

```bash
# 编辑定时任务
crontab -e
```

添加以下内容（Python 模式为例）：

```cron
# 每天凌晨 3 点自动备份数据库（保留带日期的副本）
0 3 * * * cp /www/wwwroot/money-app/backend/money.db /www/wwwroot/money-app/backend/money.db.$(date +\%Y\%m\%d)

# 每天凌晨 3 点 10 分备份上传文件
10 3 * * * tar -czf /www/wwwroot/money-app-backup-$(date +\%Y\%m\%d).tar.gz /www/wwwroot/money-app/backend/uploads/

# 每天凌晨 4 点清理 30 天前的数据库备份
0 4 * * * find /www/wwwroot/money-app/backend/ -name "money.db.2*" -mtime +30 -delete

# 每天凌晨 4 点 10 分清理 30 天前的文件备份
10 4 * * * find /www/wwwroot/ -name "money-app-backup-*.tar.gz" -mtime +30 -delete
```

> Docker 模式将路径中的 `backend/money.db` 改为 `data/db/money.db`，`backend/uploads/` 改为 `data/uploads/`。

验证 crontab 是否生效：

```bash
crontab -l    # 查看已配置的定时任务
```

### 服务器重启后恢复

**Python 模式**：应用已配置 supervisor 开机自启，服务器重启后会自动运行。如需手动启动：
```bash
systemctl start supervisord
```

**Docker 模式**：容器已配置 `restart: unless-stopped`，服务器重启后会自动运行。如需手动启动：
```bash
cd /www/wwwroot/money-app
docker compose up -d
```

## 六、注意事项

1. **前端 dist 已提交到 git**：修改前端代码后需要 `npm run build` 再提交
2. **服务器访问限制**：服务器访问外网较慢，pip 建议使用阿里云镜像加速
   - 如需 git pull，确保 GitHub 可访问，或使用 tar 包上传方式
3. **SSH 密钥**：服务器只支持密钥登录，文件上传通过宝塔面板
4. **端口配置**：
   - Python 模式：应用监听 **80 端口**，需要停止 nginx
   - Docker 模式：应用监听 **8000 端口**，通过 docker-compose 映射到 **80 端口**
   - 确保阿里云安全组已开放 **80 端口**
5. **数据库备份**：建议配置自动备份（见上方"数据备份"章节），至少每日备份 `money.db`
6. **数据库路径**：
   - Python 模式：`backend/money.db`
   - Docker 模式：`data/db/money.db`
7. **环境变量**：`SECRET_KEY` 由 deploy.sh 自动生成，生产环境请确保使用强密码
8. **隐私文件保护**：`.env`、`money.db`、`uploads/`、`*.tar.gz` 均已在 `.gitignore` 中排除，提交前用 `git status` 确认
9. **Docker 模式 Python 版本**：Dockerfile 使用 Python 3.12，服务器直接部署可能使用 3.11，两者兼容但不完全一致，注意测试

## 七、安全加固（推荐首次部署后配置）

以下操作可显著提升生产环境安全性，建议在首次部署完成后配置。

### 1. 配置 CORS 白名单

当前 `main.py` 中 CORS 配置为 `allow_origins=["*"]`，允许任意来源的跨域请求。生产环境建议限制为你的实际访问地址。

修改 [backend/app/main.py](backend/app/main.py) 中的 CORS 配置：

```python
# 生产环境：限制为实际访问地址
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://你的服务器公网IP"],  # 替换为实际地址
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

> 如果后续绑定了域名，需要同步更新此处。也可以改为从环境变量读取：
> ```python
> import os
> allowed_origins = os.getenv("ALLOWED_ORIGINS", "*").split(",")
> ```

### 2. 配置 HTTPS（强烈推荐）

HTTP 明文传输密码和 Token，存在被中间人攻击的风险。推荐通过宝塔面板配置 SSL：

1. 登录宝塔面板 → **网站** → 添加站点（绑定你的 IP 或域名）
2. 点击站点 → **SSL** → **Let's Encrypt** → 申请免费证书
3. 开启 **强制 HTTPS**

如果没有域名，也可以使用自签名证书（浏览器会提示不安全，但传输是加密的）。

### 3. 限制登录频率（防暴力破解）

当前登录接口没有频率限制，可通过宝塔面板的 WAF 或系统级 fail2ban 实现：

```bash
# 安装 fail2ban
yum install -y fail2ban 2>/dev/null || apt-get install -y fail2ban

# 启动
systemctl start fail2ban
systemctl enable fail2ban
```

### 4. supervisor 日志轮转

防止日志文件无限增长占满磁盘。编辑 supervisor 配置：

```bash
vim /etc/supervisord.d/money-app.ini
```

在 `[program:money-app]` 段落中添加：

```ini
stdout_logfile_maxbytes=10MB
stdout_logfile_backups=5
stderr_logfile_maxbytes=10MB
stderr_logfile_backups=5
```

然后重启 supervisor：

```bash
supervisorctl reread
supervisorctl update
supervisorctl restart money-app
```

## 八、数据库 Schema 变更与迁移

当代码中修改了数据库模型（新增字段、新增表等），服务器上的 SQLite 数据库不会自动更新。需要手动执行迁移。

### 迁移步骤

1. **本地测试迁移脚本**（如果项目中有 `backend/migrate_to_*.py`）：
   ```bash
   cd h:\code\money.app\backend
   python migrate_to_v1.2.py
   ```

2. **备份服务器数据库**（必须）：
   ```bash
   cp /www/wwwroot/money-app/backend/money.db /www/wwwroot/money-app/backend/money.db.bak.$(date +%Y%m%d)
   ```

3. **停止应用**：
   ```bash
   supervisorctl stop money-app
   ```

4. **拉取代码并执行迁移**：
   ```bash
   cd /www/wwwroot/money-app
   git pull origin main
   source backend/venv/bin/activate
   python backend/migrate_to_v1.2.py
   ```

5. **重启应用**：
   ```bash
   supervisorctl restart money-app
   ```

6. **验证**：浏览器访问确认功能正常。

> **SQLModel 自动建表**：对于**新增表**，应用启动时 `create_all_tables()` 会自动创建，无需手动迁移。但**已有表的字段变更**需要手动迁移脚本。
