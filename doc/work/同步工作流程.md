## 一、首次服务器部署

### 1. 初始化服务器

```bash
# SSH 或 Workbench 登录服务器后执行
cd /www/wwwroot
# 上传项目代码（通过宝塔面板文件管理器上传 tar 包）
# 或者配置 SSH 密钥后 git clone
```

### 2. 执行部署脚本

```bash
cd /www/wwwroot/money-app
chmod +x setup.sh
sudo bash setup.sh      # 首次：安装依赖
chmod +x deploy.sh
sudo bash deploy.sh      # 部署应用
```

### 3. 验证

浏览器访问 http://<你的服务器公网IP> 确认应用正常。

## 二、日常开发部署流程

### 流程图

```
本地修改代码 → 本地测试 → git add + commit → git push → 服务器 git pull → supervisorctl restart
```

### 详细步骤

#### 1. 本地修改代码

在本地电脑（Windows）修改代码。

#### 2. 本地测试

```powershell
# 启动后端
cd h:\code\money.app\backend
python -m uvicorn app.main:app --reload --port 8000

# 启动前端（另一个终端）
cd h:\code\money.app\frontend
npm run dev
```

确认修改没问题后继续下一步。

#### 3. 构建前端（如果修改了前端代码）

```powershell
cd h:\code\money.app\frontend
npm run build
```

#### 4. 提交并推送到 GitHub

```powershell
cd h:\code\money.app
git add .
git commit -m "fix: 修复xxx问题"
git push origin main
```

#### 5. 服务器更新部署

登录宝塔面板 → **终端** 或 Workbench 远程连接，执行：

```bash
cd /www/wwwroot/money-app

# 拉取最新代码（包含后端和前端 dist）
git pull origin main

# 重启应用
supervisorctl restart money-app
```

#### 6. 验证

浏览器访问 http://<你的服务器公网IP> 确认修改生效。

## 三、数据同步方案

### 推荐方案：不同步

本地开发环境和服务器生产环境的数据（数据库、上传文件）建议**分开管理，不同步**：

- **本地**：开发测试用，可随意造测试数据
- **服务器**：真实数据，用户使用

每次修改代码后，只需要 `git push` → `git pull` → `supervisorctl restart` 即可，无需同步数据。

### 需要同步数据时

**从服务器下载数据库到本地（调试用）：**

通过宝塔面板：文件 → `/www/wwwroot/money-app/backend/` → 下载 `money.db`

**从本地上传数据库到服务器：**

通过宝塔面板上传 `money.db` 到 `/www/wwwroot/money-app/backend/`

## 四、运维常用命令

### 进程管理

```bash
# 查看应用状态
supervisorctl status money-app

# 重启应用
supervisorctl restart money-app

# 停止应用
supervisorctl stop money-app

# 启动应用
supervisorctl start money-app
```

### 日志查看

```bash
# 查看实时日志
tail -f /var/log/money-app.out.log

# 查看错误日志
tail -f /var/log/money-app.err.log
```

### 数据备份

```bash
# 备份数据库
cp /www/wwwroot/money-app/backend/money.db /www/wwwroot/money-app/backend/money.db.bak

# 备份上传文件
tar -czf /www/wwwroot/money-app-backup-$(date +%Y%m%d).tar.gz /www/wwwroot/money-app/backend/uploads/
```

### 服务器重启后恢复

应用已配置 supervisor 开机自启，服务器重启后会自动运行。如需手动启动：

```bash
systemctl start supervisord
```

## 五、文件结构说明

```
money-app/
├── backend/                # 后端代码
│   ├── app/               # FastAPI 应用
│   ├── venv/              # Python 虚拟环境
│   ├── money.db           # SQLite 数据库（本地开发用）

│   └── dist/              # 构建产物（已提交到 git）
├── data/                  # 服务器数据目录（Docker 模式用）
├── deploy.sh              # 部署脚本（支持 python/docker 两种模式）
├── setup.sh               # 服务器首次初始化脚本
├── Dockerfile             # Docker 镜像定义
├── docker-compose.yml     # Docker 编排配置
└── .env.example           # 环境变量模板
```

## 六、注意事项

1. **前端 dist 已提交到 git**：修改前端代码后需要 `npm run build` 再提交
2. **服务器访问限制**：服务器无法访问外网，pip 使用阿里云镜像
3. **SSH 密钥**：服务器只支持密钥登录，文件上传通过宝塔面板
4. **端口 80**：需要停止 nginx 才能使用
5. **数据库备份**：建议定期备份 `money.db` 和 `uploads/` 目录
