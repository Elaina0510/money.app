# 模块 4：登录页 - 错误提示优化

> 需求编号：#5 | 优先级：高 | 文件：`frontend/src/api/request.js`

## 目标

登录失败时显示后端返回的"用户名或密码错误"，而非通用的"登录已过期，请重新登录"。

## 任务清单

- [ ] **4.1** 修改响应拦截器的错误处理器：对 401 状态码，优先从 `error.response.data.message` 读取后端返回的错误信息
- [ ] **4.2** 当 `data.message` 存在时（登录接口的 401），直接使用该消息；当 `data.message` 不存在时（token 过期的真实 401），显示"登录已过期"并清除 token
- [ ] **4.3** 同步优化 422 和 500 状态码的错误信息读取（优先使用 `data.message`）
- [ ] **4.4** 验证：输入错误密码，显示"用户名或密码错误"
- [ ] **4.5** 验证：输入不存在的用户名，显示"用户名或密码错误"
- [ ] **4.6** 验证：不泄露具体错误类型（不提示"用户不存在"或"密码错误"）
- [ ] **4.7** 验证：Token 过期访问业务接口，显示"登录已过期，请重新登录"
- [ ] **4.8** 验证：网络异常显示"网络异常"，超时显示"请求超时"
