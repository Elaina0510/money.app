## 2. Bug 修复清单

### Bug 1：竖屏模式侧边栏过宽

| 项目 | 说明 |
|------|------|
| **现象** | 竖屏（手机）模式下，左侧边栏展开后面积占比过大，宽屏模式正常。 |
| **修复要求** | 缩小竖屏模式下的侧边栏宽度，使其占屏幕比例合理。 |
| **验收标准** | 竖屏打开侧边栏，宽度明显变窄，不遮挡过多内容区域。 |

### Bug 2：设置页 — 分类管理/标签管理无法新增

| 项目 | 说明 |
|------|------|
| **现象** | 设置页中的分类管理和标签管理，点击新增按钮后弹出输入框，但输入名称后无法保存。 |
| **修复要求** | 修复保存逻辑，确保新增分类/标签功能正常可用。交互方式保持现有设计不变（弹出输入框 → 输入名称 → 保存）。 |
| **验收标准** | 在设置页可正常新增分类和标签，新增后列表中即时显示。 |

### Bug 3：设置页第一次打开显示空白

| 项目 | 说明 |
|------|------|
| **现象** | 从任意页面第一次点击进入设置页时，左侧边栏正常显示，但设置页内容区域为空白。从别的页面再次切换回设置页才会显示内容。 |
| **修复要求** | 修复设置页首次加载时内容不渲染的问题。 |
| **验收标准** | 从任意页面点击进入设置页，首次即可正常显示内容。 |

### Bug 4：记账表单 — 支出/收入图标在竖屏下占比不均

| 项目 | 说明 |
|------|------|
| **现象** | 竖屏模式下，记账表单页（RecordFormPage）顶部的"支出"和"收入"两个切换图标大小不一致，支出图标过大挤占了收入图标的空间。 |
| **修复要求** | 支出和收入两个图标/按钮根据屏幕宽度自适应，始终等宽等高，各占一半。 |
| **验收标准** | 竖屏下支出和收入两个按钮大小完全一致，平分可用宽度。 |

### Bug 5：记账表单 — 支出/收入图标在宽屏下偏移

| 项目 | 说明 |
|------|------|
| **现象** | 宽屏模式下，记账表单页的"支出"和"收入"图标未居中显示，偏移造成视觉不佳。 |
| **修复要求** | 将支出/收入切换按钮居中显示。 |
| **验收标准** | 宽屏下支出和收入按钮居中排列，视觉对齐。 |

### Bug 6：编辑/删除按钮存在相同的排版问题

| 项目 | 说明 |
|------|------|
| **现象** | 账单详情页或编辑页底部的"编辑"和"删除"按钮，同样存在竖屏下占比不均、宽屏下未居中的问题。 |
| **修复要求** | 将编辑和删除按钮与 Bug 4/5 一并修复，确保竖屏下等宽、宽屏下居中。 |
| **验收标准** | 所有页面底部的双按钮（编辑/删除、支出/收入等）在竖屏和宽屏下均排版正常。 |

### Bug 7：账单页 — 类型筛选无效

| 项目 | 说明 |
|------|------|
| **现象** | 账单列表页（RecordListPage）的筛选功能中，选择"分类"筛选正常工作，但选择"类型"（收入/支出）筛选后列表无任何变化。 |
| **修复要求** | 修复类型筛选逻辑，使其与分类筛选一样正常生效。 |
| **验收标准** | 在账单页选择类型（收入/支出）后，列表只显示对应类型的账单；同时选择类型+分类时，两个条件同时生效。 |

### Bug 8：快速记账 — 填入历史时间

| 项目 | 说明 |
|------|------|
| **现象** | 在记账表单页底部的"快速记账"区域，点击历史记录模板时，会把历史记录的时间也一并填入，导致时间被覆盖。 |
| **修复要求** | 点击快速记账模板时，只自动填入分类、标签、备注，时间字段保持当前时间不变。 |
| **验收标准** | 点击快速记账模板 → 分类、标签、备注自动填入，时间保持当前时间。 |

### Bug 9：注册登录后数据隔离问题（1）— 旧数据归属

| 项目 | 说明 |
|------|------|
| **现象** | 在添加登录功能之前，用户已经在使用 app 记账。注册登录功能上线后，用户注册新账号登录，之前未登录时记录的账单全部出现了在新账号中。 |
| **需求** | 旧数据（注册登录功能上线前录入的、未绑定用户的账单）只归属于**第一个注册的账号**。后续再注册其他新账号时，这些旧数据不应出现在新账号中。 |
| **验收标准** | 第一个注册的账号登录后，可看到该设备上此前未登录时录入的所有旧账单；第二个及之后注册的账号看不到这些旧数据。 |

### Bug 10：注册登录后数据隔离问题（2）— 跨账号数据泄露

| 项目 | 说明 |
|------|------|
| **现象** | 注册账号 A → 录入账单 → 退出登录 → 注册新账号 B → 账号 A 录入的账单仍然出现在账号 B 中。 |
| **修复要求** | 确保每个账号只能看到属于自己的账单数据。退出登录后重新注册新账号，旧账号的数据不应出现在新账号中。 |
| **验收标准** | 不同账号之间的账单数据完全隔离，互不可见。 |

## 3. 功能完善

### 功能 1：预算页支持编辑

| 项目 | 说明 |
|------|------|
| **背景** | 当前预算页显示固定的 3500 金额，无法修改；底部分类预算也不是用户实际的数据。 |
| **需求** | 预算页支持编辑功能，交互流程：点击预算 → 进入编辑状态 → 修改金额 → 保存。 |
| **编辑内容** | 总预算金额、各分类预算金额均可编辑。 |
| **验收标准** | 用户可修改总预算和各分类预算，保存后数值更新并持久化。 |

### 功能 2：统计页 — 分类统计柱状图

| 项目 | 说明 |
|------|------|
| **背景** | 统计页的分类统计区域当前完全空白，无任何显示。 |
| **需求** | 显示柱状图，展示每个分类下账单的总金额。 |
| **图表规格** | - 横轴：分类名称<br>- 纵轴：金额<br>- 每个分类使用不同颜色区分<br>- 使用柱状图（bar chart） |
| **验收标准** | 统计页显示柱状图，各分类及金额正确展示，不同分类颜色不同。 |

### 功能 3：账单页新增月份切换横条

| 项目 | 说明 |
|------|------|
| **背景** | 当前账单页直接显示所有月份的账单列表，无法按月筛选。 |
| **需求** | 在账单页标题栏下方新增一个横向月份切换横条。 |
| **横条内容** | 显示月份标签：一月、二月、三月……十二月。 |
| **年份标注规则** | - 当前年份的月份（如 2026 年的各月）：只显示月份名称，不显示年份<br>- 过去年份的月份（如 2025 年及更早）：在月份名称下方用小字标注年份<br>- 例如：当前是 2026 年 5 月，横条显示为「五月」「六月」…不含年份，而「2025 年的十二月」下方小字标注"2025" |
| **交互** | - 竖屏模式：横条可左右滑动查看更多月份<br>- 宽屏模式：横条两侧提供左右箭头按钮，点击按钮切换月份<br>- 点击某个月份标签，下方账单列表切换为该月份的账单<br>- 默认选中当前月份<br>- 同一时间只显示一个月份的账单 |
| **验收标准** | 月份横条正确显示，年份标注符合规则，点击切换月份后列表更新，可滑动查看更多月份。 |

### 功能 4：快速记账区域改为记录标签

| 项目 | 说明 |
|------|------|
| **背景** | 记账表单页底部"快速记账"区域，当前展示和记录的模板是基于分类，用户希望改为基于标签。 |
| **需求** | 快速记账区域展示的是历史使用过的**标签**（tag）模板，而不是分类（category）。点击某个标签模板后，自动填入该标签对应的分类、标签和备注。 |
| **与 Bug 8 的关系** | 此功能与 Bug 8 配合：点击快速记账模板时只填入分类、标签、备注，不修改时间。 |
| **验收标准** | 快速记账区域展示的是标签记录，点击后正确填入对应信息，时间不受影响。 |

## 4. 界面设计变更

### 4.1 竖屏侧边栏宽度

缩小竖屏模式下侧边栏的展开宽度，使其更紧凑、不遮挡主内容区域。

### 4.2 双按钮布局统一

全局统一「支出/收入」、「编辑/删除」等成对按钮的布局：
- **竖屏**：两按钮等宽，各占 50%
- **宽屏**：两按钮居中排列

### 4.3 月份切换横条

在账单列表页标题栏下方新增月份横条：

```
┌──────────────────────────────────────────┐
│  一月  二月  三月  四月  五月  六月  → 滑动  │
│                2025             2025     │
│  (过去年份的月份下方标注年份，当前年不标注)    │
└──────────────────────────────────────────┘
```

### 4.4 统计页柱状图

统计页新增柱状图区域，替代当前的空白区域。

## 附录：变更总结（v1.1 → v1.2）

| 维度 | v1.1 | v1.2 |
|------|------|------|
| 竖屏侧边栏宽度 | 当前宽度（偏宽） | 缩小至合适宽度 |
| 设置页分类/标签 | 新增按钮无法保存 | 修复保存逻辑，正常新增 |
| 设置页首次加载 | 空白 | 正常显示 |
| 预算页 | 固定显示 3500，不可编辑 | 支持编辑和保存 |
| 统计页分类统计 | 完全空白 | 柱状图（分类 vs 金额） |
| 账单页 | 无月份筛选 | 新增月份横条，可滑动切换月份 |
| 账单页筛选 | 类型筛选无效 | 类型和分类筛选均正常 |
| 快速记账 | 记录分类 + 填入历史时间 | 记录标签 + 不修改时间 |
| 数据隔离 | 跨账号数据泄露 | 账号间数据完全隔离 |
| 旧数据归属 | 未处理 | 自动关联到第一个注册的账号 |
| 双按钮排版 | 竖屏不等宽、宽屏不居中 | 竖屏等宽、宽屏居中 |
