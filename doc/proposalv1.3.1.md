## 详细需求

### REQ-001 账单详情页展开动画

**问题描述：**
账单页点击进入账单详情时动画丢失。

**改进目标：**
实现从点击位置开始的展开动画，具体效果为：元素从点击处开始，逐渐放大扩展至四周，直至全屏。

**验收标准：**
- [ ] 点击账单条目时，动画从点击位置（坐标）开始
- [ ] 动画过渡自然，无闪烁或卡顿
- [ ] 扩展过程平滑，直至详情页全屏显示
- [ ] 支持多种设备尺寸下的动画表现一致

---

### REQ-002 账单页筛选列表UI优化

**问题描述：**
账单页筛选列表中的类型、分类筛选区域样式简陋（纯白框），与整体设计风格不协调。

**改进目标：**
使用 Vuetify 3 的 Material You 风格组件（如 `v-chip`、`v-select`）替换现有筛选UI，使其与整体设计风格统一。

**验收标准：**
- [ ] 筛选组件使用 Vuetify 3 原生组件或符合 Material You 风格
- [ ] 筛选组件样式与整体UI风格协调
- [ ] 筛选功能保持不变
- [ ] 支持深色/浅色模式下的样式适配

---

### REQ-003 全局阴影与层级设计

**问题描述：**
整体UI缺乏层级感，元素之间的视觉层次不明显。

**改进目标：**
为每个框格、方块、字体等元素设置符合 Material You 设计规范的阴影效果，遵循Z轴深度原则：
- 底层元素（如背景卡片）：轻微阴影
- 中层元素（如按钮、输入框）：中等阴影
- 顶层元素（如弹窗、浮层）：较重阴影

**验收标准：**
- [ ] 所有卡片类元素具有适当阴影
- [ ] 按钮、输入框等交互元素具有适当阴影
- [ ] 弹窗、浮层等高层级元素具有较重阴影
- [ ] 深色/浅色模式下阴影效果均自然
- [ ] 阴影不影响元素可点击区域和交互

---

### REQ-004 首页标题栏调整

**问题描述：**
首页存在两个标题显示区域（顶部栏和内容区中部），造成视觉重复。

**改进目标：**
- 将页面标题始终固定于画面顶端（保持在前台）
- 删除内容区中部重复的标题显示区域

**验收标准：**
- [ ] 页面滚动时，顶部标题栏固定不动
- [ ] 内容区中部不再显示重复的标题
- [ ] 标题在所有页面保持一致的固定位置
- [ ] 标题固定后不遮挡下方内容

---

### REQ-005 图标水波纹涟漪动效

**问题描述：**
当前悬停图标无反馈效果，触发图标时缺乏视觉反馈。

**改进目标：**
- 悬停图标效果保持现状不变
- 触发（点击）图标时增加水波纹涟漪（Ripple）效果
- 涟漪从点击位置散开，直至碰到图标边框

**验收标准：**
- [ ] 点击图标时产生水波纹涟漪效果
- [ ] 涟漪从精确点击位置开始扩散
- [ ] 涟漪在碰到图标边框时停止
- [ ] 涟漪动画自然流畅，不影响点击响应速度
- [ ] 使用 Vuetify 的 `v-ripple` 指令或自定义实现

---

### REQ-006 快速记账页日期时间栏布局调整

**问题描述：**
快速记账页的消费日期栏边框宽度不足，时间选择被收纳（折叠）显示，不够直观。

**改进目标：**
- 增加日期栏边框宽度，使其更清晰展现日期内容
- 将具体时间选择与日期框在同一行显示，时间靠右对齐
- 布局示例：`[ 2026-06-07 日期框 ]  [ 12:30 时间选择 ]`

**验收标准：**
- [ ] 日期栏边框宽度增加，日期内容清晰可读
- [ ] 具体时间与日期在同一行显示
- [ ] 时间选择靠右对齐
- [ ] 时间选择不再折叠收纳
- [ ] 日期和时间选择功能正常

---

### REQ-007 时间选择器UI优化

**问题描述：**
点击具体时间时，弹出的选项框风格与整体设计不符。

**改进目标：**
使用 Vuetify 3 的时间选择器组件（`v-time-picker` 或 `v-menu` + 时间选择），做成时钟样式，匹配当前日历组件的设计风格。

**验收标准：**
- [ ] 时间选择器采用时钟样式
- [ ] 使用 Vuetify 3 原生时间选择组件
- [ ] 时间选择器样式与日历组件风格统一
- [ ] 支持深色/浅色模式下的样式适配
- [ ] 时间选择后正确回显到输入框

---

### REQ-008 深色/浅色模式自动切换功能

**问题描述：**
应用当前支持手动切换深色/浅色模式，但缺少跟随系统自动切换的能力。

**改进目标：**
在设置页新增"自动"模式选项，支持三种模式：
- **自动**：跟随系统状态自动切换深色/浅色
- **深色**：始终使用深色模式（已有）
- **浅色**：始终使用浅色模式（已有）

深色/浅色的呈现效果保持不变，仅新增自动模式。

**验收标准：**
- [ ] 设置页深色/浅色模式切换栏新增"自动"选项
- [ ] 选择"自动"时跟随系统 `prefers-color-scheme` 设置
- [ ] 系统主题变化时应用自动切换，无需刷新页面
- [ ] 用户选择持久化保存（localStorage）
- [ ] 已有的手动深色/浅色切换功能不受影响

| 响应式 | 适配桌面端和平板端显示 |
