# Money App v1.2.1 需求文档

> 版本：v1.2.1  
> 日期：2026-05-31  
> 基于：v1.2  
> 目标：补全 v1.2 遗留未完成功能 + 修复 v1.2 上线后新发现的 Bug

---

## 一、版本概述

v1.2 部分功能未完成或效果未达预期，同时上线后用户反馈了 9 个新问题。本次 v1.2.1 将两类问题合并修复。

| 类别 | 数量 |
|------|:---:|
| 🐛 Bug 修复（v1.2 遗留 + 新发现） | 13 项 |
| ✨ 功能补全（v1.2 未完成） | 4 项 |

---

## 二、Bug 修复清单

### Bug 1：竖屏侧边栏仍然过宽

| 项目 | 说明 |
|------|------|
| **现状** | v1.2 已设置窄屏宽度为 72px，但用户反馈仍然偏宽，视觉上遮挡内容区域过多 |
| **修复方案** | 将竖屏模式下侧边栏宽度从 72px 缩小至 56px，同时隐藏侧边栏文字标题（仅保留图标），使侧边栏更紧凑 |
| **验收标准** | 竖屏打开侧边栏，宽度明显变窄，仅显示图标，不遮挡过多内容 |

---

### Bug 2：快速记账时间被重置

| 项目 | 说明 |
|------|------|
| **现状** | 快速记账模板点击后，`fillTemplate()` 函数会将 `consumeDate` 和 `consumeTime` 覆盖为历史记录的时间 |
| **修复方案** | `fillTemplate()` 中删除对 `consumeDate` 和 `consumeTime` 的赋值，仅填入分类、标签、备注，时间保持当前时间不变 |
| **验收标准** | 点击快速记账模板 → 分类、标签、备注自动填入，时间保持当前时间 |

---

### Bug 3：账单页缺少月份切换横条

| 项目 | 说明 |
|------|------|
| **现状** | 账单页仅有日期范围筛选器，无月份切换横条 |
| **修复方案** | 在账单页标题栏下方新增横向滑动月份条 |
| **横条规格** | 月份标签：`1月 2月 3月 ... 12月`，当前年份不标注年份，过去年份下方小字标注年份 |
| **交互** | 默认选中当前月份；点击月份后刷新该月账单；竖屏可左右滑动；宽屏提供箭头切换 |
| **验收标准** | 月份横条正确显示，点击切换月份后列表更新 |

---

### Bug 4：快速记账区域显示改为标签

| 项目 | 说明 |
|------|------|
| **现状** | 快速记账模板 chip 显示 `category_name · ¥金额`，未显示标签 |
| **修复方案** | 模板 chip 改为显示标签名（优先显示 `tag` 字段），若无标签则回退显示分类名 |
| **验收标准** | 快速记账区域展示的是标签记录，点击后正确填入对应信息 |

---

### Bug 5：标签删除确认问题

| 项目 | 说明 |
|------|------|
| **现状** | 设置页标签管理，点击"删除"图标弹出确认框，但在确认之前标签已被删除 |
| **修复方案** | 检查删除逻辑，确保 `deleteTag()` 只在用户确认后才调用 API，确认前不执行任何删除操作 |
| **验收标准** | 点击删除 → 弹出确认框 → 确认后才执行删除 → 取消则不删除 |

---

### Bug 6：预设分类支持删除

| 项目 | 说明 |
|------|------|
| **现状** | 预设分类（`is_preset=1`）不支持删除，且删除操作不同步到其他页面 |
| **修复方案** | 1. 移除预设分类的"不可删除"限制<br>2. 删除分类后，全页面同步更新（通过 Pinia Store 刷新）<br>3. 删除分类时检查关联账单：<br>　- 有关联账单：弹出确认框 `"该分类下有 N 条账单记录，删除分类将同时删除所有关联账单，确认删除？"`<br>　- 无关联账单：直接删除<br>4. 后端 `delete_category` 接口需接受 `current_user` 参数，验证所有权 |
| **验收标准** | 预设分类可删除；有关联账单时需确认；删除后所有页面同步更新 |

---

### Bug 7：重新登录后边栏不显示用户数据

| 项目 | 说明 |
|------|------|
| **现状** | 重新登录后左侧边栏不显示用户名，需要刷新页面才生效 |
| **修复方案** | 登录成功后，立即将 token/username/userId 写入 localStorage，并通过 `window.dispatchEvent(new Event('auth:login'))` 通知 AppLayout 组件刷新登录状态 |
| **验收标准** | 登录后侧边栏立即显示用户名，无需刷新 |

---

### Bug 8：深色模式滚动条未适配

| 项目 | 说明 |
|------|------|
| **现状** | 深色模式下滚动条仍为浅色，与深色背景不协调 |
| **修复方案** | 在全局样式中添加深色模式滚动条适配：<br>轨道：`rgba(255,255,255,0.1)`<br>滑块：`rgba(255,255,255,0.3)` |
| **验收标准** | 深色模式下滚动条与背景协调 |

---

### Bug 9：深色模式文字颜色易读性差

| 项目 | 说明 |
|------|------|
| **现状** | 深色模式下正文文字为黑色字体，在深色背景上几乎不可见 |
| **修复方案** | 深色模式下正文文字颜色改为浅灰白色（如 `#E0E0E0`），标题保持白色（`#FFFFFF`），正文亮度略低 |
| **验收标准** | 深色模式下所有文字清晰可读 |

---

### Bug 10：数据隔离 — 更新/删除无所有权校验

| 项目 | 说明 |
|------|------|
| **现状** | 查询操作正确过滤 `user_id`，但更新/删除操作不验证所有权，任何用户可通过 ID 修改/删除他人数据 |
| **修复方案** | 在以下 service 的 update/delete 方法中增加 `current_user` 参数，操作前验证资源的 `user_id` 是否匹配：<br>- `record_service.update_record()` / `delete_record()` / `batch_delete_records()`<br>- `category_service.update_category()` / `delete_category()`<br>- `tag_service.update_tag()` / `delete_tag()` |
| **验收标准** | 用户只能操作自己的数据，操作他人数据返回 403 |

---

### Bug 11：统计页分类柱状图显示"暂无数据"

| 项目 | 说明 |
|------|------|
| **现状** | 统计页分类统计区域使用饼图（Pie），但 v1.2 需求要求使用柱状图（Bar），且显示"暂无数据" |
| **修复方案** | 1. 将分类统计图表从饼图改为柱状图（Bar chart）<br>2. 注册 `BarElement` 和 `BarController`<br>3. 横轴：分类名称，纵轴：金额，不同分类使用不同颜色 |
| **验收标准** | 统计页显示柱状图，各分类及金额正确展示 |

---

### Bug 12：记账页支出/收入按钮比例失衡

| 项目 | 说明 |
|------|------|
| **现状** | v1.1 版本中「支出」和「收入」按钮等宽并排、各占 50%；v1.2 中「支出」按钮占据大部分宽度，「收入」被挤到右侧，大小严重不一致 |
| **修复方案** | 检查 `RecordFormPage.vue` 中支出/收入按钮的布局 CSS，确保两个按钮使用 `flex: 1` 或等宽布局，在所有屏幕尺寸下均等宽显示 |
| **验收标准** | 「支出」和「收入」按钮在竖屏和宽屏下均等宽并排，各占 50% 宽度 |

---

### Bug 13：设置页分类管理不显示分类列表

| 项目 | 说明 |
|------|------|
| **现状** | v1.1 设置页分类管理正常显示所有分类（含图标、名称、预设标签、编辑/删除按钮）；v1.2 分类管理显示"暂无分类"，分类数据未加载 |
| **可能原因** | 1. `category_service.get_categories()` 返回的数据格式与前端不匹配<br>2. 分类数据查询未正确返回预设分类<br>3. 前端 `SettingsPage.vue` 的分类数据绑定有误 |
| **修复方案** | 排查分类列表加载流程：后端 API 返回 → 前端 Store → SettingsPage 渲染，定位数据断点并修复 |
| **验收标准** | 设置页分类管理正常显示所有分类，包括预设分类和用户自定义分类，带有图标、名称、预设标签和操作按钮 |

## 三、功能补全清单

### 功能 1：预算页支持编辑

| 项目 | 说明 |
|------|------|
| **现状** | 预算页数据为硬编码静态数组，`saveBudget()` 为空函数，未调用后端 API |
| **修复方案** | 1. 前端 `BudgetPage.vue` 从后端 API 加载预算数据（`GET /api/budgets`）<br>2. 实现编辑功能：点击预算项进入编辑状态，修改金额后保存（`PUT /api/budgets/{id}`）<br>3. 总预算金额和各分类预算金额均可编辑<br>4. 保存后数据持久化到后端 |
| **验收标准** | 用户可修改总预算和各分类预算，保存后数值更新并持久化 |

## 六、v1.2 → v1.2.1 变更总结

| 维度 | v1.2 现状 | v1.2.1 目标 |
|------|----------|------------|
| 竖屏侧边栏 | 72px，仍偏宽 | 56px，仅图标 |
| 快速记账 | 填入历史时间 | 保留当前时间 |
| 快速记账显示 | 显示分类名 | 显示标签名 |
| 账单页 | 无月份切换 | 横向月份条 |
| 统计页分类图 | 饼图，显示暂无数据 | 柱状图，正确展示 |
| 预算页 | 硬编码数据，不可编辑 | 从 API 加载，支持编辑 |
| 标签删除 | 确认前已删除 | 确认后才删除 |
| 预设分类 | 不可删除 | 可删除，关联账单一并处理 |
| 登录后边栏 | 需刷新才显示用户 | 立即显示 |
| 深色模式 | 文字不可见，滚动条不适配 | 文字清晰，滚动条适配 |
| 数据隔离 | 读操作隔离，写操作无校验 | 全操作隔离 |
| 支出/收入按钮 | 比例失衡，支出占大部分 | 等宽并排，各占 50% |
| 设置页分类管理 | 显示"暂无分类" | 正常显示完整分类列表 |
